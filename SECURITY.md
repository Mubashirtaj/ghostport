# Security Policy

## Supported Versions

GhostPort is pre-1.0 and moves fast. Only the latest released version
is supported with security fixes — please upgrade before reporting an
issue to confirm it's still reproducible.

| Version         | Supported          |
| --------------- | ------------------- |
| Latest release  | :white_check_mark: |
| Older releases  | :x:                 |

## Reporting a Vulnerability

Please report security vulnerabilities privately using
[GitHub Security Advisories](https://github.com/mubashirtaj/ghostport/security/advisories/new)
for this repository, rather than opening a public issue.

Include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (OS/platform, GhostPort version, exact commands)
- Any relevant logs or output

You can expect an initial response within 5 business days. If the
report is confirmed, a fix will be prioritized and a new release cut;
you'll be credited in the advisory unless you'd prefer otherwise. If
declined, you'll get an explanation of why it's not considered a
vulnerability or is out of scope.
