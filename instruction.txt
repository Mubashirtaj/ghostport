Build me a complete production-ready CLI tool called GhostPort in Go.

PROJECT IDEA:
A tool that explains and kills what's using a local port. Not just PID, but human-readable info.
Command: ghostport 8080
Output: "Port 8080 is being used by your Docker container (postgres-db) started 2 hours ago. Do you want to kill it?"

REQUIREMENTS:

1. CORE FEATURES:
- cmd/root.go: `ghostport [port]` - Find process using that port and show detailed info: PID, Process Name, CWD (project folder), Cmdline, CreateTime (how long running), and whether it's a Docker container.
- internal/detector.go: Use github.com/shirou/gopsutil/v4/net and process to find port owner. Must work on Linux, Mac, Windows. Parse TCP LISTEN connections.
- internal/docker.go: Function IsDockerPort(port) - run `docker ps --format "{{.Ports}}|{{.Names}}"` and check if port is used by a container. Return container name if found.
- internal/killer.go: KillPID(pid) - cross platform kill.
- cmd/list.go: `ghostport list` - Show table of common dev ports (3000, 3001, 3000, 5173, 8000, 8080, 5432) and their status using lipgloss table.

2. CLI & UI:
- Use cobra for CLI framework.
- Use charmbracelet/lipgloss for beautiful, screenshot-worthy output. Box with colors.
- Output example:
  👻 GhostPort v0.1.0

  → Process: node (PID: 8421)
  → Project: ~/code/my-app
  → Running: npm run dev
  → Docker: postgres-db container
  Prompt: [k] Kill, [o] Open folder, [q] Quit
